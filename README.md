## 📖 Deskripsi

Repositori ini berisi kumpulan tugas dan proyek yang dikerjakan selama mengikuti mata kuliah **Pemrograman Website**. Seluruh materi disusun untuk mempelajari dasar pengembangan web, mulai dari struktur halaman dengan HTML, penataan tampilan dengan CSS, hingga interaktivitas dengan JavaScript.

---

## 🎯 Tujuan Pembelajaran

- Memahami struktur dasar dan semantik dokumen HTML.
- Menerapkan CSS untuk membangun tampilan yang rapi dan responsif.
- Menggunakan JavaScript untuk menambah interaktivitas halaman.
- Menerapkan version control menggunakan Git dan GitHub.

